# Styl'sBox 🎵

A simple and efficient **Discord music bot** that lets you play audio directly from YouTube links in your voice channels.

---

## Features

- **Play music** from YouTube URLs
- **Pause**, **Resume**, and **Stop** playback
- Lightweight and easy to use
- Connects to voice channels automatically

---

## Commands

| Command         | Description                  |
|-----------------|------------------------------|
| `?play <url>`   | Play audio from a YouTube link |
| `?pause`        | Pause the current song       |
| `?resume`       | Resume the paused song       |
| `?stop`         | Stop the song and disconnect |

> Use `?help` to see the command list in Discord!
